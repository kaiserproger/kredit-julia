# kredit-julia — дообученная Julia-1 для kredit

Веса decision-модели для необязательной ИИ-подсказки в [kredit](https://github.com/kaiserproger/kredit)
(«Умный кредитный кабинет предпринимателя», Альфа-Хак 2026).

- База: [SupersonicLabs/Julia-1](https://huggingface.co/SupersonicLabs/Julia-1) (144M, mmBERT-small), Apache-2.0.
- Дообучение: CPU, синтетические русские тексты предпринимателей, сгенерированные командой (персональных данных нет).
- Файл: `model.safetensors` в релизе `v1`, SHA-256 `aafb9652044fffb1f850a5a55ffd70dc67adff224b7045244a1e73a0af2e1d01`.
- Загрузка: `ai/julia-service/fetch_weights.sh` в репозитории kredit (проверяет SHA-256); токенизатор и конфиг берутся из закреплённой ревизии базовой модели.

## Что модель делает в kredit

Только подсказывает клиенту, клиент подтверждает сам. В кредитное решение не попадает.

| Вопрос | Слепой тест (200 новых текстов) | 95% интервал |
|---|---|---|
| Продукт (оборотный кредит / оборудование / не нужен) | 95,3% | 91,2–97,5% |
| Бизнес моложе 12 месяцев | 96,5% | 92,5–98,4% |
| Есть регулярная выручка | 94,9% | 90,6–97,3% |

Отрасль и сезонность не прошли порог и в продукте не используются. Модель не воздерживается
на неоднозначных текстах; с ними точность ниже (90,5 / 81,5 / 84,0%). Данные синтетические —
это не доказательство качества на реальных заявках.
